# AI Sales Assistant (MVP) 

Прототип умного ИИ-консультанта для интернет-магазина, разработанный в рамках AI-хакатона (Трек: Торговля). 

Система решает проблему долгого поиска товаров и паралича выбора: покупатель просто описывает свою задачу свободным текстом, а ИИ анализирует каталог и предлагает 2-3 лучших варианта с персонализированной аргументацией.

## Стек технологий
* **Python 3.10+**
* **Streamlit** — быстрый UI и серверная логика
* **OpenAI API (gpt-4o-mini)** — LLM для анализа потребностей и выбора товаров
* **JSON (Mock DB)** — эмуляция базы данных товаров
